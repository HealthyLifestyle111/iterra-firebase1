# Iterra Firebase - doTERRA Referral Management Platform

A React-based web application for managing doTERRA associate referral links with automated tracking and analytics.

- **[Project Status & Next Steps](./PROJECT_STATUS.md)** - Comprehensive update on what's been implemented and what to do next
- **[PR #1 - Implementation](https://github.com/HealthyLifestyle111/iterra-firebase1/pull/1)** - Full implementation with screenshots

## 🚀 Features

- 🔐 Firebase Authentication (email/password)
- 📊 Real-time referral click tracking
- 🔗 Automatic slug generation from email addresses
- 📈 Admin dashboard for monitoring associates
- ⚡ Smart redirect system with fallback
- 🎨 Responsive UI with loading states

## 🏃 Quick Start

Once deployed, the platform provides:

1. **Landing Page** (`/`) - Public page with product information
2. **Associate Signup** (`/associate`) - Register and get your referral link
3. **Admin Dashboard** (`/admin`) - Monitor all associates and statistics
4. **Redirect System** (`/go/:slug`) - Track clicks and redirect to doTERRA
